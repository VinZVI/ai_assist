# Этап 1.2: Система персонажей и сценариев

## Обзор

Этап 1.2 реализует систему персонажей и сценариев для ролевых игр в Telegram боте. Это позволяет пользователям взаимодействовать с различными ИИ-персонажами в различных сценариях, создавая более разнообразный и увлекательный опыт общения.

## Новые сущности данных

### Персонажи (Characters)
- Полнофункциональные ИИ-персонажи с детализированными профилями
- Поддержка различных полов, возрастов и характеров
- Системные промпты для определения поведения персонажа
- Статистика популярности и рейтингов
- Возможность создания пользовательских персонажей

### Сценарии (Scenarios)
- Предопределенные сценарии для ролевых игр
- Настраиваемые начальные промпты
- Возрастные ограничения
- Статистика использования

### Чаты (Chats)
- Отдельные чаты для каждой комбинации пользователь-персонаж-сценарий
- Управление памятью с настраиваемым сроком хранения
- Статистика сообщений

### Сообщения чата (ChatMessages)
- Расширенная модель сообщений с метаданными
- Поддержка различных типов сообщений (пользователь, ИИ, системные)
- Отслеживание времени генерации и количества токенов

### Теги персонажей (CharacterTags)
- Система категоризации персонажей
- Уникальные теги для каждого персонажа

### Рейтинги персонажей (CharacterRatings)
- Система лайков/дизлайков для персонажей
- Отслеживание оценок отдельных пользователей

## Обновления существующих моделей

### Модель пользователя (User)
- Новые связи с чатами, персонажами и рейтингами
- Дополнительная статистика (общее количество чатов, отправленных сообщений)
- Поле для любимого персонажа

## Сервисы данных

### CharacterService
- Поиск и фильтрация персонажей
- Управление рейтингами и тегами
- Получение статистики персонажей

### ChatService
- Создание и управление чатами
- Добавление сообщений в чаты
- Очистка просроченных чатов
- Получение истории сообщений

## Преимущества

1. **Разнообразие взаимодействия**: Пользователи могут общаться с различными персонажами в разных сценариях
2. **Персонализация**: Возможность создания собственных персонажей
3. **Статистика**: Подробная аналитика использования
4. **Масштабируемость**: Модульная архитектура для будущих расширений

## Технические детали

- Все новые таблицы поддерживают индексы для оптимизации производительности
- Реализована система внешних ключей для обеспечения целостности данных
- Поддержка каскадного удаления для автоматической очистки связанных данных
