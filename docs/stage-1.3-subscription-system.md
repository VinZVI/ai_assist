# Этап 1.3: Обновленная система подписок

## Обзор

Этап 1.3 реализует полностью переработанную систему подписок с 5 уровнями, заменяя упрощенную премиум-модель на более гибкую и детализированную систему с различными преимуществами для каждого уровня.

## Новые уровни подписки

### 1. Бесплатная подписка (Free)
- 20 сообщений в день
- Только кэш (без сохранения истории)
- Реклама
- Низкий приоритет в очереди

### 2. Стандартная подписка (Standard) - 100 ⭐
- 100 сообщений в день
- 7 дней хранения истории
- Без рекламы
- Приоритет в очереди

### 3. Премиум подписка (Premium) - 300 ⭐
- 300 сообщений в день
- Генерация изображений (60 в день)
- 30 дней хранения истории
- Приоритет в очереди
- Без рекламы

### 4. Deluxe подписка (Deluxe) - 500 ⭐
- Безлимитные сообщения
- Безлимитная генерация изображений
- Постоянное хранение истории
- Высший приоритет в очереди
- Без рекламы

### 5. Админ подписка (Admin)
- Все возможности Deluxe
- Доступ к админ-функциям
- Специальные привилегии

## Новые модели данных

### Подписки (Subscriptions)
- Расширенная модель подписки с детализированными настройками
- Отслеживание статуса и сроков действия
- Информация о платежах и провайдерах
- Кэширование лимитов для оптимизации производительности

### Использование подписки (SubscriptionUsage)
- Ежедневное отслеживание использования лимитов
- Отдельные счетчики для сообщений, изображений, персонажей и сценариев
- История использования для аналитики

## Конфигурация уровней

Система использует централизованную конфигурацию через `SubscriptionConfig`, что позволяет легко настраивать параметры каждого уровня подписки.

## Сервис управления подписками

### SubscriptionService
- Получение и создание подписок пользователей
- Обновление подписок при оплате
- Проверка лимитов использования
- Получение статистики использования
- Управление сроками действия подписок

## Интеграция с существующими системами

### RateLimitMiddleware
- Заменяет устаревшую систему ограничения частоты запросов
- Интегрируется с SubscriptionService для проверки лимитов
- Предоставляет информативные сообщения о превышении лимитов

### SubscriptionHandler
- Обработчики команд управления подпиской
- Создание счетов для оплаты через Telegram Stars
- Обработка успешных платежей

## Преимущества новой системы

1. **Гибкость**: 5 уровней подписки с различными комбинациями преимуществ
2. **Детализация**: Отдельные лимиты для разных типов активности
3. **Производительность**: Кэширование лимитов и ежедневное отслеживание использования
4. **Масштабируемость**: Легко добавлять новые уровни и функции
5. **Интеграция**: Плавная интеграция с существующими системами бота

## Технические детали

- Все таблицы поддерживают индексы для оптимизации производительности
- Реализована система внешних ключей для обеспечения целостности данных
- Поддержка каскадного удаления для автоматической очистки связанных данных
- Использование перечислений для типов подписок и статусов
- Уникальные ограничения для предотвращения дублирования записей использования
