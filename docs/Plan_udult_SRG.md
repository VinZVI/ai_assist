# Детальный план трансформации AI-Компаньон в бота для взрослого контента с внедрением Schema-Guided Reasoning

## Анализ текущего состояния и требований

На основе анализа существующего кода AI-Компаньон и спецификации из features_ai_bot.txt, проект необходимо трансформировать из универсального ИИ-помощника в специализированный бот для интерактивного общения с ИИ-персонажами с поддержкой контента для взрослых.[1]

**Ключевые изменения:**
- Система персонажей с детализированными профилями
- Сценарии для ролевых игр
- Многоуровневая система подписок
- Генерация изображений для премиум пользователей
- Schema-Guided Reasoning для структурированного мышления ИИ
- Строгие меры безопасности и возрастной верификации

## Этап 1: Подготовка инфраструктуры и соответствие требованиям (2-3 недели)

### 1.1 Юридическое соответствие и безопасность

**Критические компоненты:**
- **Система возрастной верификации** - обязательная проверка совершеннолетия перед доступом
- **Модерация контента** - автоматическая и ручная модерация генерируемого контента
- **Соблюдение законодательства** - внедрение требований Online Safety Act, GDPR, местного законодательства[2][3]
- **Отказоустойчивость** - backup системы для блокировки недопустимого контента

### 1.2 Обновление базы данных

**Новые модели:**
- **Characters** - персонажи с детальными профилями
- **Scenarios** - сценарии для ролевых игр  
- **Chats** - отдельные чаты для каждой комбинации персонаж+сценарий
- **AgeVerification** - записи о верификации возраста
- **ContentModerationLog** - логи модерации

**Расширение существующих моделей:**

### 1.3 Обновление системы подписок

**Новые уровни подписки согласно спецификации:**[1]

3. **Премиум**: 300 сообщений/день, генерация изображений (60/день), 30 дней хранения

5. **Админ**: полный доступ ко всем функциям

## Этап 2: Внедрение Schema-Guided Reasoning (SGR) (2-3 недели)

### 2.1 Архитектура SGR системы

**Schema-Guided Reasoning** - это методика структурирования мышления ИИ через предопределенные схемы, обеспечивающая предсказуемые, аудируемые и качественные ответы.[4][2]

**Компоненты SGR для проекта:**
```
app/
├── sgr/
│   ├── schemas/
│   │   ├── character_response_schema.py   # Схема ответов персонажей
│   │   ├── scenario_planning_schema.py    # Схема планирования сценариев
│   │   ├── content_safety_schema.py       # Схема проверки безопасности
│   │   └── image_generation_schema.py     # Схема генерации изображений
│   ├── reasoning/
│   │   ├── character_reasoner.py          # Рассуждения персонажа
│   │   ├── scenario_reasoner.py           # Логика сценариев
│   │   └── safety_reasoner.py             # Проверка безопасности
│   └── validators/
│       ├── response_validator.py          # Валидация ответов
│       └── content_validator.py           # Валидация контента
```

### 2.2 Схемы для персонажей и сценариев

**Пример схемы ответа персонажа:**
```python
class CharacterResponseSchema(BaseModel):
    # Этап 1: Анализ контекста
    context_analysis: str = Field(description="Анализ текущей ситуации и настроения")
    character_state: str = Field(description="Текущее эмоциональное состояние персонажа")
    
    # Этап 2: Планирование ответа
    response_intent: str = Field(description="Намерение ответа (флирт, поддержка, игра)")
    tone_selection: str = Field(description="Выбранный тон общения")
    
    # Этап 3: Генерация контента
    dialogue: str = Field(description="Основной диалог персонажа")
    actions: str = Field(description="Описание действий и мимики")
    
    # Этап 4: Проверка безопасности
    content_safety_check: bool = Field(description="Прошла ли проверку безопасности")
    safety_notes: Optional[str] = Field(description="Заметки по безопасности")
```

### 2.3 Интеграция SGR с существующей AI системой

**Модификация AI Manager:**

## Технические требования для SGR

### Основные принципы SGR для проекта:

1. **Структурированное мышление** - каждый ответ ИИ проходит через определенные этапы
2. **Валидация на каждом шаге** - проверка корректности на каждом этапе схемы
3. **Аудируемость** - возможность проследить логику принятия решений
4. **Предсказуемость** - одинаковые входные данные дают консистентные результаты
5. **Безопасность** - встроенные проверки безопасности на каждом уровне

### Архитектура SGR интеграции:

```python
# Пример использования SGR в характере персонажа
class CharacterAI:
    def __init__(self, character_profile, scenario_context):
        self.sgr_engine = SGREngine()
        self.character_schema = CharacterResponseSchema()
        
    async def generate_response(self, user_message):
        # SGR обеспечивает структурированный процесс мышления
        structured_response = await self.sgr_engine.process(
            schema=self.character_schema,
            context={
                "character": self.character_profile,
                "scenario": self.scenario_context,
                "user_input": user_message
            }
        )
        return structured_response
```
